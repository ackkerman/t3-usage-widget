# 検証観点

## Happy Path
取得済みの使用量と Limits を表示用の数値に変換する。

## Edge Cases
ゼロと未取得を区別し、大きな数値や部分取得を扱う。

## Failure Cases
未接続・認証失敗・非対応時は失敗状態を表示し、数値を捏造しない。

## Security
資格情報がログや共有スナップショットへ出ない。

## Regression Tests
金額の推定表示とトークン数の変換を確認する。

## Manual Verification
接続後、T3 の同一期間の値とデスクトップウィジェットを照合する。T3 停止時、ダークモード、VoiceOver を確認する。

## Integration Tests
- この Mac の起動中 T3 に短命の読み取りセッションで接続し、集計とプロバイダー上限の応答を取得する。
- 価格不明のレコードがある場合、既知分の推定額と未価格分を含まないことを表示する。
- 共有領域に認証情報を保存しない。
- ホストと拡張のループバック通信が実機で機能し、資格情報を送らないことを確認する。
- ループバック以外で待ち受けず、認証情報を含まない読み取り応答だけを返す。
- ホストが停止した場合、ウィジェットは未接続を示す。期限切れのスナップショットを最新と見せない。
- 全ての使用元が欠落・失敗し、レコードもない場合、トークンとコストをゼロでなく未取得とする。
- 有効な使用元があり、期間内のレコードがない場合はゼロを表示する。
- 取得途中・価格不明のレコードは部分取得として扱い、既知分の推定額と明示する。
- `make check` で Swift の書式検査、ビルド、自動テストを実行する。
- WidgetKit のプレビューではサンプルと明示し、通常表示では取得したスナップショットのみ表示する。
- 通信ポートが占有されている場合はアプリが更新成功を表示せず、待ち受け失敗を表示する。
- 取得時刻の30分後に期限切れ表示のタイムラインを設定する。境界以降の古いデータ、未来の不正時刻、未接続は未接続として扱う。
- 使用量 API の契約バージョンが対応範囲外なら、受信した数値を表示せずエラーとする。対応範囲内は集計する。
- 過去24時間は分単位で切り捨てた現在時刻から24時間の範囲を使う。7・30・90日はタイムゾーンの暦日で計算する。
- 夏時間の切替を跨ぐ暦日と、日付を跨ぐ24時間で開始日・終了日を正しく設定する。
- 期間の変更中は旧期間の値を新期間の値として表示しない。選択した期間はアプリ再起動後も保持する。
- 小サイズで長いプロバイダー名がある場合も、利用上限の使用率を省略せず表示する。
- 小・中・大サイズのプレビューで複数の利用上限を表示し、各サイズの表示上限と省略件数を確認する。
- 複数のバケットをプロバイダー単位で合算し、価格不明レコードがあるプロバイダーは既知分の推定額を表示する。他のプロバイダーの既知のコストは保持する。
- 大サイズでプロバイダー別の値と利用上限が収まり、表示枠を超えた件数が分かることを Simulator で確認する。
- Cost・Tokens・Limits の切替が1つのウィジェット内で動作し、それぞれ添付の画面に対応する実データを表示する。
- 期間別・プロバイダー別・種類別の合計と日別系列、上限の残量とリセット時刻を T3 と照合する。
- 複数環境を集計する場合は重複を防ぎ、未接続の環境を欠落扱いとして表示する。
- メニューバー項目を開閉でき、ホストウィンドウを閉じても定期更新とウィジェット連携が維持される。
- メニューバーとウィジェットの Cost・Tokens・Limits と期間の選択が相互に反映される。
- ローカルの表示切替 POST にブラウザーの Origin・Referer・Fetch Metadata がある場合は拒否する。
- コスト不明の期間をグラフの線で補間せず、その前後を別の系列として描画する。
- 同じソース指紋が複数環境から報告された場合、T3 と同じ状態・取得時刻の優先順位で一度だけ計上する。
- より新しい部分スキャンに完全スキャンにはない日・時間・モデルのバケットがある場合、重複セルを足さず新しいセルだけ補完する。
- 異なる期間やモデルフィルターの集計は混ぜない。ソース指紋やパスをウィジェットへ送信しない。
- リモート URL は HTTPS のみ受け入れ、接続先の環境 ID が変わった場合は資格情報を送信しない。認証付きリクエストのリダイレクトを拒否する。
- ローカル配置時にホストアプリが起動中なら上書きを拒否する。別のバンドル ID や別の実行ファイルは変更しない。
- 更新前のウィジェット拡張だけを識別して終了し、更新後の登録と描画を確認する。
- システム言語の日本語・英語・簡体字・繁体字と、対応外言語の英語フォールバックを確認する。
- 手動言語設定を切り替えるとホスト・メニューバー・ウィジェットの文言と日付表示が変わり、再起動後も保持される。
- データ取得中・未接続・部分取得・価格不明の文言と VoiceOver ラベルを各言語で確認する。
- Cost・Tokens・Limits のアイコンが各モードに対応し、選択状態と翻訳された VoiceOver 名・ヘルプを持つ。
- 言語・更新・終了のアイコンが操作でき、意味の異なる数値や期間は文字で識別できる。
- 期限切れの未接続表示でも、それまで選んだタブと言語を保持する。
- アプリで手動選択した言語がギャラリーのサンプルにも反映され、ホスト停止時にも最後の言語設定を使用する。
- アプリアイコンがアセットカタログからビルド済みアプリに取り込まれ、署名検証を通る。
- Finder とウィジェット一覧で T3 Usage のアイコンが判別でき、小さいサイズでも識別できる。
- 別環境の接続先は HTTPS のみ受け付け、環境 ID が一致しない場合はコードもトークンも送信しない。
- ローカルと別環境を同じ期間で取得して重複を除外し、片方の障害を部分取得として示す。
- 接続解除で専用 Keychain 項目と設定を削除し、他アプリの認証情報に触れない。
- 価格既知と未設定が混在するときは既知分の推定コストを表示し、未設定分を除くと明示する。全件不明ならゼロにしない。
- 不正レコードを除外した partial なスキャンは、価格表示を修正しても部分取得として残す。
- macOS の Finder／検索のアイコンで灰色の二重枠が付かず、T3 本体と同程度の大きさで識別できる。
- 「このアプリについて」に T3 Usage のアイコンが表示される。
